# Mermaid source ownership validation

## Scope

This slice closes the cross-family audit raised by Requirement finding R-S1.
It covers flowchart, sequence, state, journey, quadrant, XY, Sankey, Radar, Requirement, pie and timeline.
It does not close the remaining diagram coverage or human acceptance gates.

## Source authority

A source interval can contain the expected equation while belonging to a different field.
Two fields with identical TeX demonstrate why byte matching alone is insufficient.

The parser parent captures a private JSON receipt from each successful isolated worker result.
Its key binds the diagram family, request flags, rendered source and exact original fence.
Receipts contain the final worker transport, after native reconciliation and renderer-copy planning.
Pie and timeline receipts contain the records projected into their figures.

Each source-map entry reconstructs the original fence from document bytes and authenticates its transport against the receipt.
The existing transport, resource and display-coordinate checks remain in place.
An absent receipt triggers bounded worker revalidation using the same source and family.
Cache clearing and worker-path changes clear receipts.

Cached results and returned results have separate object graphs.
Deleting a returned transport or changing nested records cannot affect another document's cache hit.
A modified returned payload also fails receipt comparison when supplied directly to a source mapper.

## Review corrections

- R-S1: Every activated family now authenticates grammar ownership, including coherent swaps between equal equations.
- SO-01: Pie and timeline distinguish absent records from explicit empty arrays. Stripped arrays must authenticate and fail.
- SO-02: Fresh and cached parse results are detached from private cache storage. Whole-property deletion cannot suppress later math validation.

## Verification

The focused suite has 24 tests. Eleven family cases verify equal-byte coordinate swaps, returned-result mutation and wrong-source replay.
They also verify legitimate detached clones after receipt clearing and exact raw bytes before and after each swap.
Eleven additional cases delete transport properties from fresh and cached results, then require restored transport and valid mapping.
Two cases reject explicit empty pie and timeline arrays.

Existing source-map fixtures now use production worker payloads instead of synthesized slot or copy plans.
Genuine folded YAML, aliases, fanout, Unicode, BOM, CRLF, comments and encoded-delimiter checks remain.
XY tests reject visibility changes after parsing and retain an accessibility-only empty map.

The integrated suite passes 770 tests across 118 files. Typecheck, build and asset/reference budgets pass.
Installed offline HTML checks pass at 320/1440, including exact references, readable fallbacks and print source.
Independent review found no remaining material defect in this slice. Timing checks were not run.
